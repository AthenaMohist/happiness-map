# 住得爽指数 (happiness-map)

> 小区幸福度地图 · 像玩文明一样看懂你家小区 · 微信小程序 + Telegram Mini App

以真实地图为底座，给小区幸福度排名。设施即资源：必需品缺了扣分，稀有/战略/奇观按文明规则加分，一切分数按「人群 × 年收入」双维度分列。
